## 1. Inspiration

### Manu Arora

[Portfolio](https://www.manuarora.in/) · [Aceternity UI](https://ui.aceternity.com/)

My v1 portfolio was heavily inspired by Manu Arora, who was himself inspired by [Akash Bhadange](https://www.designerdada.com/).

Things I like:

- Aceternity UI's [Link Preview](https://ui.aceternity.com/components/link-preview).
- Animated SVG signature in the footer.
- Clean and minimal presentation.

### Hanzla

[Portfolio](https://developer-portfolio-1hanzla100.vercel.app/) · [Source Code](https://github.com/1hanzla100/developer-portfolio)

I like its dark, content-heavy and straightforward design. It doesn't rely on flashy animations or trendy effects.

Things to explore:

- Typography and content hierarchy.
- Dark visual identity.
- Simple layouts and presentation.

### Aditya Patil

[Portfolio](https://www.justaditya.com/)

A lot of interesting ideas and features, although the number of sections and repetitive layouts can make navigation confusing.

Things I like:

- Talk with me card.
- Personal About section.
- Different ways of presenting information.

## 2. Ideas for v2

These are initial ideas, not finalized requirements.

- **Link Preview:** Explore [Aceternity UI's Link Preview](https://ui.aceternity.com/components/link-preview), inspired by Manu Arora.
- **Dedicated About Section:** Explore [Minimal Portfolio](https://ui.aceternity.com/template-preview/minimal-portfolio-template) and [Sidefolio](https://ui.aceternity.com/template-preview/sidefolio-portfolio-template).
- **Animated Dark Mode:** Try [Skiper4](https://skiper-ui.com/v1/skiper4) from Skiper UI.
- **Talk with Me Card:** Inspired by [Aditya Patil](https://www.justaditya.com/).
- **Animated SVG Signature:** Explore an animated personal signature for the footer.
- **Agent Mode:** Provide an alternative Markdown representation of the entire portfolio so AI agents can read its content directly without scraping the visual website.
- **Subtle Animations:** Keep interactions smooth, professional and understated rather than flashy.

## 3. UI Libraries

### beUI

[beui.dev](https://beui.dev/)

- Large collection of free components.
- Subtle and professional animations.
- Clean, reusable UI components.
- My likely primary choice for animated components in v2.

### Aceternity UI

[ui.aceternity.com](https://ui.aceternity.com/)

- Professionally animated components.
- Useful for distinctive interactions.
- Some components are paid.

### Skiper UI

[skiper-ui.com](https://skiper-ui.com/)

- Unique and less common components.
- Interesting animation concepts.
- Some components are paid.

**Initial preference:** Use beUI as the primary source for animated components, while selectively borrowing useful components from Aceternity UI and Skiper UI.

## 4. Things to Figure Out

Before starting the actual design and implementation, I still need to figure out:

- What is the actual purpose of my portfolio?
- Whom do I want to attract?
- What should visitors take away from it?
- Which sections are genuinely necessary?
- What should make v2 different from v1?
- What visual direction should I follow?
- How much personality and animation should I introduce?

I want to retain a minimal and professional portfolio while introducing more personality through thoughtful interactions, better content presentation and subtle animations.

Nothing is finalized yet.

**Next step:** Figure out the purpose, target audience and overall direction of the portfolio before moving into design and implementation.
